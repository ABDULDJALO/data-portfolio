# 🖥️ Sistema de Gestión de Soporte TI

## 📌 Descripción

Proyecto de práctica desarrollado con MySQL para diseñar y gestionar una base de datos destinada a un departamento de soporte técnico.

El sistema permitirá registrar empleados, técnicos, equipos, departamentos, categorías de incidencias y tickets de soporte.

## 🎯 Objetivos

- Diseñar una base de datos relacional.
- Aplicar claves primarias y foráneas.
- Practicar consultas SQL.
- Utilizar JOIN, GROUP BY, HAVING y funciones de agregación.
- Analizar información de tickets de soporte.

## 🛠️ Tecnologías

- MySQL
- SQL
- GitHub
